 🧠 AI Second Brain – Personal Memory Assistant

🚀 A modern AI-powered personal assistant that helps you store, organize, and intelligently retrieve your memories using semantic search.

🌟 Overview

AI Second Brain is a smart productivity tool that allows users to:
- Store thoughts, tasks, and ideas
- Retrieve information using natural language
- Interact via a chat-based interface
- Visualize memory insights through a dashboard

It acts like your **personal knowledge base + assistant**.

 🎯 Features

💬 Chat with Memory
- Ask questions like: *“What projects am I working on?”*
- Retrieves relevant memories intelligently

➕ Add Memory
- Save thoughts with categories:
  - Work
  - Personal
  - Learning

📊 Dashboard Analytics
- Total stored memories
- Category distribution (charts)
- Recent activity tracking

🧠 Semantic Search
- Uses TF-IDF + cosine similarity
- Finds meaning, not just keywords

🎨 Modern UI
- Dark theme with gradient background
- Chat-style interface
- Clean card-based layout

🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas

⚙️ How It Works

1. User inputs data (memory or query)
2. Text is converted into vectors (TF-IDF)
3. System compares similarity using cosine similarity
4. Returns most relevant memories
